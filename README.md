# Career-Path-Guide

A simple career guidance website for students. It helps students decide what to study after 10th, after 12th and after graduation, using easy words.

## Live Demo
https://sakinatech-coder.github.io/Career-Path-Guide/

## Features
- Search any course, such as BCA, B.Com or BA (works with or without dots, like "bcom")
- Step-by-step path buttons: After 10th, After 12th, After graduation
- "I like" buttons (computers, money and business, biology and health and more) to find suitable courses
- 44 options: school streams, diplomas, degrees and master courses
- Course details window with:
  - what you will learn
  - why choose it, in easy words
  - skills you build
  - jobs you can do
  - estimated fees (government and private, per semester and total)
  - "What next?" buttons that open the next course
- Works on mobile and desktop

## Tech Stack
- HTML
- CSS
- JavaScript (no frameworks, single file)

## Note
Fees and eligibility are rough estimates for general guidance. They change by college, city and year, so always check the official college or university website.

## How to Run
1. Download or clone this repository
2. Open `index.html` in your browser
